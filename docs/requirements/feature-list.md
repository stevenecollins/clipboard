# Feature List

## MVP Features (Priority 1)

### Authentication & User Management
- [x] **Email/Password Registration**: Standard signup with email verification
- [x] **Social Login**: Google and Apple OAuth integration
- [x] **Password Reset**: Email-based password recovery
- [x] **Profile Management**: Basic user profile editing
- [x] **Account Deletion**: GDPR-compliant account removal

### Content Capture
- [x] **Mobile Share Target**: iOS/Android share extension integration
- [x] **Browser Extension Save**: Right-click context menu save
- [x] **Dual Capture**: Save both image and source URL simultaneously
- [x] **Image Optimization**: Automatic compression and format conversion
- [x] **Quick Board Selection**: Choose destination board during save

### Board Organization
- [x] **Board CRUD**: Create, read, update, delete boards
- [x] **Item Management**: Add, remove, reorder items within boards
- [x] **Board Privacy**: All boards private by default
- [x] **Board Metadata**: Name, description, creation date
- [x] **Item Metadata**: Title, source URL, save date, board assignment

### Cross-Platform Sync
- [x] **Real-time Sync**: Changes appear across devices within 5 seconds
- [x] **Offline Support**: View and basic editing when offline
- [x] **Sync Conflict Resolution**: Automatic handling of simultaneous edits
- [x] **Device Management**: View and manage connected devices

### Viewing & Navigation
- [x] **Grid View**: Pinterest-style grid layout for visual browsing
- [x] **List View**: Compact list view with metadata
- [x] **Source Link Access**: One-click access to original URLs
- [x] **Basic Search**: Search within boards by title or URL
- [x] **Sort Options**: Sort by date, title, or board

## Post-MVP Features (Priority 2)

### Enhanced Organization
- [ ] **Tags System**: Add multiple tags to items for better organization
- [ ] **Smart Collections**: Auto-generated collections based on content type
- [ ] **Bulk Operations**: Select and move/delete multiple items
- [ ] **Board Templates**: Pre-configured board structures
- [ ] **Nested Boards**: Sub-boards for hierarchical organization

### Advanced Capture
- [ ] **Manual Upload**: Direct file upload from device
- [ ] **Camera Integration**: Capture photos directly within app
- [ ] **PDF Capture**: Save and view PDF documents
- [ ] **Video Thumbnails**: Preview thumbnails for video content
- [ ] **Full Page Screenshots**: Capture entire web pages

### Search & Discovery
- [ ] **Global Search**: Search across all boards and items
- [ ] **OCR Text Search**: Search text within saved images
- [ ] **Filter System**: Advanced filtering by date, source, tags
- [ ] **Recently Accessed**: Quick access to recently viewed items
- [ ] **Duplicate Detection**: Identify and manage duplicate saves

### Sharing & Collaboration
- [ ] **Public Board Sharing**: Share boards with public URLs
- [ ] **Collaboration Boards**: Multi-user board editing
- [ ] **Board Invitations**: Invite others to private boards
- [ ] **Export Options**: Export boards to PDF, ZIP, or other formats
- [ ] **Social Sharing**: Share individual items to social media
